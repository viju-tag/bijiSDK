# bijiSDK 0.1.0-preview.4

This preview packages the Android-tested remote configuration SDK with repeatable mobile verification tooling and recorded results.

## Install

Unity Package Manager > Install package from Git URL:

```text
https://github.com/viju-tag/bijiSDK.git?path=/clients/unity#v0.1.0-preview.4
```

Tested Unity version: 6000.0.68f1. Newtonsoft JSON 3.2.1 resolves through the package dependency.

## Changes

- Added mobile project preparation, Android IL2CPP build tooling, live Pages checks, and lifecycle diagnostics.
- Recorded Nox and physical Motorola moto g45 5G / Android15 results, including hosted update/rollback and process restart.
- Added malformed HTTP body fault coverage.
- Made sample import resolve the installed package version instead of a hardcoded version.
- Added versioning rules and pinned installation instructions.

## Validation and scope

The 35 standalone client groups passed again for release preparation. Runtime and sample C# source are unchanged from preview.3, which was tested in the ARM64 IL2CPP APK on Nox and a physical phone. Historical reports preserve that APK version and hash; no preview.4 Android rebuild is claimed.

Unity preview.4 sample import, scene setup, and transitive Newtonsoft 3.2.1 resolution passed during release preparation. Device results are documented in `verification/results-physical-android-2026-10-29.md` and `verification/results-mobile-2026-10-29.md`.

Real offline/reconnection was skipped by the user. iOS testing is deferred. Broader Android device/OS coverage, higher stripping, and controlled mobile network faults remain unverified. This is a preview release, not a claim of full production certification.

Package version changes do not alter the config wire schema, game contract version, or hosted fixture revisions.
